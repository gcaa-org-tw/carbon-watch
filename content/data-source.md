# 資料來源

「排碳大戶觀測站」資料來自以下來源：
*  政府開放資料
*  公開資訊觀測站
*  基金資訊觀測站
*  中華民國證券投資信託暨顧問商業同業公會
*  企業永續報告書
*  OpenStreetMap
*  經上述資料運算與換算後之數據

上述原始資料來源均為一般大眾可自行取得的公開資訊。本網站將原始數據進行彙整、擷取、單位換算與計算後呈現，除單位換算外，未更動原始數值；原始資料之正確性由原始提供者負責，彙整、擷取與計算過程如有錯誤，歡迎來信指正，本會將儘速更正。來信請註明［排碳大戶觀測站］以加速處理流程。

## OpenStreetMap

依燃煤使用查詢的廠區位置，以環境部「環境保護許可管理系統(暨解除列管)對象基本資料」之座標為準；該資料集未提供座標的工廠，改以 OpenStreetMap 依登記地址進行街道級定位（工廠清單中以「＊」標示），非精確廠址。

本網站取自 OpenStreetMap 的資料，僅有上述依登記地址定位所得之座標。廠區定位資料 <a href="https://www.openstreetmap.org/copyright" target="_blank">© OpenStreetMap 貢獻者</a>，依<a href="https://opendatacommons.org/licenses/odbl/1-0/" target="_blank">開放資料庫授權條款（Open Database License，ODbL）1.0</a> 提供。

## 企業永續報告書

除上述政府及公開資料來源外，本網站所呈現的企業氣候行動資訊（如淨零承諾、減量目標、再生能源規劃、範疇三揭露等），主要取自各企業最近一期公開之永續報告書。

由於目前永續報告書尚無統一格式，也缺乏經整理的開放資料，本會先以大型語言模型（Gemini 2.5 Flash）批次擷取報告書內容，再經人工校對、統一換算單位後整理公開。

若發現數據錯誤或與報告書原文不符，歡迎來信指正，本會將儘速更正。來信請註明［排碳大戶觀測站］以加速處理流程。
